# Mini Hospital Emergency Management System

CIT300 - Data Structures and Algorithms - Individual Mid Assignment

## Overview
A Java console application simulating hospital emergency management using
four core data structures: Binary Search Tree, Queue, Stack, and Singly Linked List.

## Data Structures Used
- **Binary Search Tree (PatientBST.java)** — stores patient records keyed by Patient ID; supports insert, search, delete, and in-order traversal
- **Queue (EmergencyQueue.java)** — manages patients waiting for emergency treatment (FIFO)
- **Stack (TreatmentStack.java)** — stores completed treatment history (LIFO)
- **Singly Linked List (VisitLinkedList.java)** — stores each patient's visit history

## How to Run
1. Clone this repository
2. Open the folder in VS Code (with Java Extension Pack installed) or IntelliJ
3. Run `Main.java`
4. Follow the on-screen menu

## Project Structure
- `Patient.java` — patient data model
- `PatientBST.java` — Binary Search Tree for patient records
- `EmergencyQueue.java` — queue for waiting patients
- `TreatmentStack.java` — stack for treatment history
- `Visit.java` — visit data model
- `VisitLinkedList.java` — linked list for patient visit history
- `Main.java` — menu-driven program tying everything together
